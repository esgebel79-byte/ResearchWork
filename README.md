# Neural-Physical Hybrid Forecasting of Epidemic Bifurcations via Critical Slowing Down Detection (PR-Patch)

Данный репозиторий содержит MLOps-платформу для гибридного нейрофизического прогнозирования временных рядов эпидемиологических данных (на примере COVID-19 в Санкт-Петербурге). В основе проекта лежит оригинальная архитектура **PR-Patch (Physics-Regularized PatchTST)**, интегрированная с методами обнаружения сигналов раннего предупреждения (Early Warning Signals, EWS) на основе концепции критического замедления (**Critical Slowing Down, CSD**) и механизмами объяснимого ИИ (**XAI**).

Платформа переведена из экспериментальных Jupyter-ноутбуков в промышленную модульную структуру, готовую к сквозному воспроизведению, автоматическому подбору регуляризаторов и генерации научных артефактов.

---

## 📌 Ключевые особенности и научная новизна

* **Мультивариантный согласованный конвейер (4-Channel Inputs):** Жестко синхронизированная обработка гетерогенных признаков для соблюдения балансовых соотношений: потоковых (`PCR_TESTS`), кумулятивных (`CONFIRMED.sk`, `ACTIVE.sk`) и емкостных (`OCCUPIED_BEDS_CALCULATED` — ключевой прогнозируемый таргет).
* **Физическая регуляризация на базе SIR-динамики:** Лосс-функция `PhysicsRegularizedLoss` штрафует модель за нарушение законов сохранения массы и динамики переходов между восприимчивыми ($S$), инфицированными ($I$) и удаленными ($R$) компонентами популяции в процессе обучения.
* **Латентная Cross-Attention модуляция сигналов CSD:** Механизм многоголового внимания (Multi-head Cross-Attention) связывает патч-эмбеддинги эпидемических рядов с динамически рассчитываемыми индикаторами раннего предупреждения (EWS) — скользящей дисперсией (`rolling_variance`) и авторегрессионным коэффициентом `AR(1)`. При приближении к точкам излома тренда (бифуркациям) модель адаптивно перестраивает веса внимания.
* **H-шаговая траекторная верификация (Cumulative PCE):** Расчет ошибки физической консистентности (Physics Consistency Error, PCE) выполняется интегрально по всей сгенерированной авторегрессионной траектории на горизонт $H=14$ дней вперед.
* **Многокритериальный анализ Парето-оптимальности:** Автоматический многокритериальный сеточный поиск (Grid Search) по пространству гиперпараметра физической регуляризации $\lambda$ с вычислением фронта Парето в осях $MSE$ (точность) — $PCE$ (физическая адекватность) для строгого численного обоснования выбора рабочей точки.

🛠️ Инструкция по развертыванию и запуску

1. Подготовка окружения
Рекомендуемая версия Python: 3.11+. Склонируйте репозиторий, создайте виртуальное окружение и установите зависимости:

git clone [https://github.com/esgebel79-byte/ResearchWork.git](https://github.com/esgebel79-byte/ResearchWork.git)
cd ResearchWork
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows
pip install -r requirements.txt

2. Запуск интеграционного теста 
Для верификации прохождения градиентов через блоки Cross-Attention, проверки геометрии входных тензоров и работоспособности физического лосса без обращения к физическим дискам выполните:

python integration_pipeline_test.py

3. Запуск полного сквозного нейрофизического конвейера
Вся логика исследований автоматизирована внутри единой точки входа main.py. Запуск выполняется одной командой:

python main.py

При этом конвейер последовательно выполняет 3 ключевых шага:
Шаг 1: Загрузка мультивариантного датасета, агрегация потоков и вычисление скользящих индикаторов критического замедления (EWS).
Шаг 2: Обучение семейства моделей PRPatchModel на сетке значений lambda [0.0, 0.01, 0.05, 0.1, 0.5, 1.0], локализация точек перелома тренда алгоритмом сдвига скользящих наклонов и расчет локальных метрик MSE / PCE с сохранением в artifacts/metrics/.
Шаг 3: Поиск точек излома эпидемического тренда, автоматический выбор сбалансированной модели (\lambda = 0.05) и генерация карт важности признаков методами SHAP (с деагрегацией патчей в физические лаги) и LIME в окрестностях бифуркаций.
